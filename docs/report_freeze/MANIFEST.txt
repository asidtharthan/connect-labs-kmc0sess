IDENTIFIERS
------------------------------------------------------------------------------
Every file above is re-keyed: FLW_xxxxxxxx, SESS_xxxxxxxx, TRIG_xxxxxxxx. Verified across all
9 files: zero Connect ids, zero session or form UUIDs, no names, phones, LGAs, settlements.
Codes are stable across files, so they join to each other.

Reversing it needs the salt AND the code map. Neither is in this folder or in git, and they
are the only things that undo it. Round-trip verified on all 10,535 session rows.
